# Бенчмарк подбора со скрытой истиной

200 потребностей × 2000 кандидатов = 400 000 пар. Версия bench-v2, алгоритм match-v1, конфиг `19255e3a8b95`, seed мира 20261006, второй мир 20261007. Пересчёт: `make bench` (90 с на общей машине с 2 ядрами).

> Синтетика проверяет механику подбора — что ранжирование достаёт подходящих кандидатов из шумных данных так, как задумано, — а не реальный рынок: мир, шум и функция истины заданы нами. Экспертная разметка пар «потребность — кандидат» — отдельная проверка на людях.

## Выводы

- Платформа против BM25 по тексту резюме: nDCG@10 +0,19 [0,16; 0,22], p@5 0,79 против 0,44, MRR 0,89 против 0,65.
- Тест — главный вклад: без него (только самоописание) nDCG@10 ниже на 0,18 [0,13; 0,22]; только грейд из теста без скора внутри категории — ниже на 0,15.
- Раздутые резюме: нерелевантные «раздутые» занимают 4 % мест топ-10 у платформы, 31 % у BM25, 54 % без теста и 13 %, если засчитывать заявленные навыки как подтверждённые.
- Цена защиты от раздувания: засчитывание заявленных навыков дало бы nDCG@10 +0,08 (при 20 % «раздутых»). Если 40 % кандидатов дописывают все навыки направления, такой вариант уже не выигрывает у платформы (0,55 против 0,57, мир 60 × 600), а у платформы nDCG@10 почти не меняется (0,57 → 0,57). Заявленное (T0) в скор не входит намеренно — это устойчивость к атаке «дописать навыки вакансии».
- Бонус ФСП: вклад в nDCG@10 −0,001 [−0,009; 0,008] — на точность не влияет. Он переставляет подходящих: доля кандидатов без ФСП среди подходящих в топ-10 36 % (без бонуса 56 %, среди всех подходящих 66 %); средний перцентиль места подходящих без ФСП 0,17, с ФСП 0,11.
- Слабое место — потребности уровня Junior: nDCG@10 0,49 против 0,73 у самоописания. Тест у порога Junior осторожен (подтверждение от P = 0,8 при SE ≈ 0,4): часть подходящих не подтверждает грейд (381 из 2000 без категории). Дотестирование у порога в синтетике не моделируется.
- Junior у порога при одной истине: прежний порог 0,6 оставлял без категории 465 кандидатов, правило банка с порогом 0,8 — 683, «Junior (предварительно)» возвращает в категорию 302 (ложных предварительных — истинный уровень ниже порога — 33 % из них); ложные отказы заявившим Junior с истинным уровнем не ниже порога: 16 % → 28 % → 3 %. nDCG@10 по Junior-потребностям 0,50 / 0,49 / 0,49, p@5 0,68 / 0,66 / 0,66.
- Штраф «предварительно» 0 / 0,05 / 0,10 меняет nDCG@10 по Junior-потребностям на 0,493 / 0,493 / 0,493; доля предварительных в топ-10 Junior-потребностей 0 % / 0 % / 0 %, перцентиль места подходящих предварительных 0,075 / 0,081 / 0,085. Предварительные у порога почти не попадают в верх выдачи и без штрафа (компонент теста у них мал), поэтому в мире из 2000 кандидатов штраф на топ-10 не влияет; штраф 0,05 задан до бенчмарка (вес одного зонда) и на нём не подбирался.
- При строгой истине (подходит только точный грейд) nDCG@10 платформы 0,40, BM25 0,36: выбор правила истины меняет абсолютные числа, поэтому сравнивать их с бенчмарками других команд нельзя — сравнимы только методы внутри одного мира.

## Как устроено

- Кандидат = скрытая истина (направление, истинный уровень θ*, освоенные навыки, талант) + то, что видит система: самоописание T0 (шумное; 20 % «раздутых» резюме, 15 % «скромных»), тест T1 (θ̂ = θ* + N(0, σθ), σθ = 0,48 — RMSE нашего адаптивного теста в симуляции; решение по грейду — правилом банка (подтверждение от P = 0,8, у порога Junior — «Junior (предварительно)»), при отказе — пересдача ступенью ниже; навыки — по ответам на задания с тегами из банка), паспорт ФСП T2 у части кандидатов.
- Потребность = истина (направление, грейд, 2–4 обязательных навыка) + текст; платформа получает только разбор текста парсером.
- Ранжирование платформы — `ranking.score_candidate` без изменений; Bundle собирается только из наблюдаемого. Скор, пересобранный из компонент, совпадает с продуктом (макс. расхождение 1e-04).

Истинная релевантность (0–3):

- Направление кандидата не совпадает с направлением потребности → 0.
- Истинный грейд — по истинному уровню θ* и порогам платформы (−1 / 0 / 1), ниже порога Junior — ступень 0. Равен запрошенному или на ступень выше (может выполнять эту работу) → 2; на ступень ниже или на две выше (переквалифицирован) → 1; на две ниже → 0.
- Может выполнять работу и реально владеет ≥ 75 % обязательных навыков → 3.
- Владеет < 50 % обязательных навыков → не выше 1.
- Релевантен — метка ≥ 2. Желательные навыки, формат работы и зарплата в истину не входят.
- Строгий вариант (в анализе чувствительности): 2 — только точный грейд, соседний в любую сторону → 1.
