# Разбор потребности на вакансиях hh.ru (Я12)

Корпус собран 2026-10-10: 193 вакансий (в прогоне 193, недоступно 0, текст изменился с даты сбора: 0). Прогон 2026-10-10, код `ed93c28`. Пересчёт: `cd backend && python ../tools/realdata/hh_corpus.py run` (нужен токен приложения hh.ru; тексты — в локальном кэше).

Корпус — только для проверки разбора (ответ организаторов FTT.6: парсинг допустим для тестовых данных, не как продуктовая механика). В репозитории — номера, ссылки и производные метки (`docs/realdata/hh_corpus.json`), тексты вакансий не хранятся.

**Методика.** Путь правил need_parser.parse_need(use_llm=False) на названии и описании (key_skills парсеру не даются). Метки — структурированные поля hh.ru: роль → направление, слово грейда в названии → грейд, experience → диапазон лет, work_format → формат, key_skills → теги справочника. Опыт и формат: «согласовано» — значение парсера внутри поля hh.ru (доля от найденных); отрицания — текст с «опыт не требуется» → разбор не требует опыта, «удалёнка не предусмотрена / только офис» → не «удалённо» (явные 0 лет и «офис» — отдельно). Методика и поля — как у замера Я11 на 50 вакансиях (`tools/realdata/parse_compare.py`), корпус шире и метки независимы от текста. Метки — серебряные (поля hh.ru заполняет работодатель; грейд в названии — не экспертная разметка).
