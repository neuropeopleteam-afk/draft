## Правило

1. После основного теста (≤ 60 мин, решение при P ≥ 0,6; итог первой сессии g, заявленный грейд c) уровень **«на границе»**, если у порогов уровней от g до c включительно (выше g, не выше заявленного) P(θ ≥ порога) лежит строго между 1 − L и L (то же, что |θ̂ − порог| < z_L · SE); граница — порог с P, ближайшей к 0,5. Вид: «уровень под вопросом» (порог — уровень g, keep) или «возможно выше» (порог выше g, не выше c, up). Режим «выше заявленного» (above > 0): если g = c и уровень выше c вероятен с P ≥ above.
2. До уточнения — уровень по первой сессии с пометкой «на границе: можно уточнить» (не выше, чем позволяет первая сессия).
3. **Уточнение уровня** — отдельная сессия: только короткие задания (≤ 5 мин) с наибольшей информацией у выбранного порога, без семейств прошлых сессий, частота показа — Sympson — Hetter; не больше N заданий и M минут; досрочно — когда после 3 новых заданий порог вышел из θ̂ ± z_L · SE.
4. **Итог** — по общей оценке обеих сессий (одна апостериорная θ̂ по всем ответам; детектор предзнания — по всем): наивысший уровень не выше заявленного с P(θ ≥ порога) ≥ c₂; выше заявленного — только в режиме above и с P ≥ c↑. Может быть и ниже первой сессии (кроме варианта «итог не ниже первой»). Уровень — только по тесту.

Повтор — вся процедура ещё раз (новый субпул, семейства обеих сессий первой попытки не берутся). Общие случайные числа: первая попытка одинакова во всех вариантах.

## В продукте

- Флаг `ASSESSMENT_TWO_STAGE_ENABLED` (по умолчанию выкл.); параметры — `ASSESSMENT_TWO_STAGE_LEVEL` (L), `_ITEMS` (N), `_MINUTES` (M), `_CONFIRM` (c₂), `_CONFIRM_UP` (c↑), `_ABOVE`, `_FLOOR`; значения по умолчанию — выбор этого прогона.
- Итог полного теста банка «на границе» → блок «На границе X/Y: можно уточнить» и кнопка «Уточнить уровень за 10–M минут»; до уточнения действует уровень по первой сессии. Уточнение — `POST /api/assessment/sessions` с `mode=refine`: одно на полный тест, правила 90 и 30 дней на него не действуют (та же оценка), лимит сессии — M + 10 минут.
- Итог уточнения — по ответам обеих сессий (ответы первой переносятся, как в дотестировании Junior); уровень записывается обычными правилами категории (подтверждение, повышение или понижение); при «без категории» прежняя категория сохраняется.
- Работодатель (карточка, подборка, поиск — общий статус грейда) видит пометку «на границе X/Y — уточнение пройдено / не пройдено / не проходил». Уровень — только по тесту.
