## Правило

1. После основного теста (≤ 60 мин, решение при P ≥ 0,6) уровень **«на границе»**, если у порога уровня кандидата или любого уровня выше P(θ ≥ порога) лежит строго между 1 − L и L (то же, что |θ̂ − порог| < z_L · SE), или уровень выше заявленного уже вероятен с P ≥ L (тест на заявленный грейд выше его не поднимает).
2. До уточнения — уровень по первой сессии с пометкой «на границе: можно уточнить».
3. **Уточнение уровня** — отдельная сессия: только короткие задания (≤ 5 мин) с наибольшей информацией у выбранного порога, без семейств прошлых сессий, частота показа — Sympson — Hetter; не больше N заданий и M минут; досрочно — когда после 3 новых заданий порог вышел из θ̂ ± z_L · SE.
4. **Итог** — по общей оценке обеих сессий (одна апостериорная θ̂ по всем ответам; детектор предзнания — по всем): наивысший уровень с P(θ ≥ порога) ≥ c₂. Может быть и ниже первой сессии. Уровень — только по тесту.

Повтор — вся процедура ещё раз (новый субпул, семейства обеих сессий первой попытки не берутся). Общие случайные числа: первая попытка одинакова во всех вариантах.
