# Test–retest всего пути кандидата и дискриминативность семейств

Подпись мира: симуляция теста: 5 направлений × 500 кандидатов, семейств в банке: 165; seed 20261006, конфигурация `a5797d8d33e4`, коммит `03b9a22`, банк `180791bef2a67b72`. Пересчёт: `make path-retest` (24 с).

> Синтетика: истинные параметры заданий = предкалибровка + ошибка эксперта σ = 0,5, люди — модель ответов 2PL; проверяется механика всей процедуры, а не качество заданий на людях. «Предварительно» считается ступенью Junior. Дискриминативность — на симулированном пилоте с авторскими параметрами: она показывает замысел автора, а не поведение людей; r_pb панели моделей — независимая проверка на ответах моделей, шкала моделей не равна шкале людей.

## Процедура

1. Опрос: стаж (θ = 0 → 1,5 года, θ = 1 → 4,5 года, шум 1 год) → подсказка грейда по стажу (как в продукте); самооценка — θ + N(0; 0,6). Заявленный грейд — подсказка (в половине случаев) или самооценка; ниже порога Стажёра — Стажёр.
2. Стек опроса фильтрует семейства (Go, Java, Django, Kafka, Docker — только тем, у кого тег есть).
3. Адаптивный тест платформы на банке: классификационная остановка, дотестирование у порога, контроль частоты, ротация субпулов по истории сессий; тест Стажёра — только лёгкие семейства, без ротации.
4. Детектор предзнания и пересчёт θ; решение: подтверждён при P ≥ 0,8, «Junior (предварительно)» при P от 0,10.
5. Не подтверждён: принять доказанный уровень ниже без нового теста (P ≥ 0,8), иначе один тест ступенью ниже, иначе без категории.
6. Повтор — вся процедура ещё раз: другой субпул, новые варианты, семейства прошлой сессии не в дотестировании.

## Флаг «общий блок сильнее направления» (консилиум 07.10, п. 7.4)

Проверка правила: доля верных в блоке направления ниже, чем в общем, на ≥ 0,3 при ≥ 4 заданиях направления. Заявлен Middle, θ общего блока ~ N(0,5; 0,5), по 150 кандидатов; θ в направлении ниже на сдвиг.

| Сдвиг θ в направлении | Флаг сработал | Middle подтверждён | Из подтверждённых с флагом |
|---|---|---|---|
| 0,0 | 7 % | 57 % | 6 % |
| 1,0 | 37 % | 24 % | 31 % |
| 3,0 | 95 % | 8 % | 92 % |

Флаг по доле верных срабатывает и у обычных кандидатов (сдвиг 0): адаптивный тест даёт блокам задания разной трудности, поэтому сырая доля верных — грубый сигнал. В объяснение результата он не добавлен; решение по грейду не меняется (консилиум: страж направления — после 11.10 с отдельной симуляцией).

## Дискриминативность семейств (симулированный пилот)

Пилот: 1000 человек на направление, θ ~ N(0; 1), каждому — все семейства общего блока и блока направления, новый вариант каждому; авторские параметры. D — доля верных в верхних 27 % минус в нижних 27 % по сумме остальных заданий; r_pb — корреляция «задание — сумма остальных».

- Семейств: 155; D: среднее 0,470, медиана 0,478; доли D ≥ 0,3 / 0,2–0,3 / < 0,2: 100 % / 0 % / 0 %.
- r_pb: среднее 0,413, медиана 0,407; r_pb > 0,2 у 100 %.
- Слабых на симуляции (D < 0,2 или r_pb < 0,2): 0 — авторские параметры по замыслу различают; это проверка замысла, не людей.
- Панель моделей (независимая проверка на ответах моделей): r_pb есть у 0 семейств, корреляция с симуляцией —; r_pb панели < 0,15 — у 0. Низкая связь авторской и модельной дискриминативности — довод за калибровку на людях после хакатона.

- Аудит банка 08.10 отдал на переделку 15 семейств (подсказки длиной верного варианта, дистракторы); из них слабые здесь: нет; средняя r_pb панели у них —. Сигналы разные: подсказка в форме облегчает задание, а не обязательно снижает различение.
