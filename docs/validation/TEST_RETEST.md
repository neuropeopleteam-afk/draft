# Test–retest всего пути кандидата и дискриминативность семейств

Подпись мира: симуляция теста: 5 направлений × 500 кандидатов, семейств в банке: 268; seed 20261006, конфигурация `2b13d6150103`, коммит `b544962`, банк `4d44ffb455f03520`. Пересчёт: `make path-retest` (69 с).

> Синтетика: истинные параметры заданий = предкалибровка + ошибка эксперта σ = 0,5, люди — модель ответов 2PL; проверяется механика всей процедуры, а не качество заданий на людях. «Предварительно» считается ступенью Junior. Дискриминативность — на симулированном пилоте с авторскими параметрами: она показывает замысел автора, а не поведение людей; r_pb панели моделей — независимая проверка на ответах моделей, шкала моделей не равна шкале людей.

## Процедура

1. Опрос: стаж (θ = 0 → 1,5 года, θ = 1 → 4,5 года, шум 1 год) → подсказка грейда по стажу (как в продукте); самооценка — θ + N(0; 0,6). Заявленный грейд — подсказка (в половине случаев) или самооценка; ниже порога Стажёра — Стажёр.
2. Стек опроса фильтрует семейства (Go, Java, Django, Kafka, Docker — только тем, у кого тег есть).
3. Адаптивный тест платформы на банке: классификационная остановка, дотестирование у порога, контроль частоты, ротация субпулов по истории сессий; тест Стажёра — только лёгкие семейства, без ротации.
4. Детектор предзнания и пересчёт θ; решение: подтверждён при P ≥ 0,6, «Junior (предварительно)» при P от 0,10.
5. Не подтверждён: принять доказанный уровень ниже без нового теста (P ≥ 0,6), иначе один тест ступенью ниже, иначе без категории.
6. Повтор — вся процедура ещё раз: другой субпул, новые варианты; семейства всех прошлых сессий не берутся (новых нет — виденные давнее всего, в новом варианте).

## Путь и точность к истине (первая попытка)

- Итоговый грейд = истинный: 66 %; среди получивших категорию — 66 %; κw с истиной 0,814.
- Грейд выше истинного: 7 %; ниже истинного (категория есть): 26 %; без категории: 3 %.
- Статусы (обе попытки): подтверждён 73 %, предварительно 4 %, принят уровень ниже 20 %, без категории 3 %.
- Сессий на путь 1,00, заданий на сессию 20,0, на путь 20,1, минут на путь 57; дотестирование у порога — в 87 % сессий.
- «Junior (предварительно)», у которых доказан Стажёр (путь «принять Стажёра»): 212.

**Повтор ≠ точность.** κ 0,869 — повторяемость, а не точность: при повторе всего пути грейд совпал у 78,7 %, а с синтетической истиной — у 65,8 % (первая попытка).

Цена порога P ≥ 0,6: правило осторожно против завышения (выше истинного — 7,1 %), поэтому чаще занижает (ниже истинного — 26,4 %, без категории — 3,1 %; «принят уровень ниже» — 20,4 % статусов). Маршрут восстановления: у порога — дотестирование (+6 заданий, до 20 мин; было в 87,4 % сессий), после — вторая попытка на новых вариантах другого субпула.

## Правило решения: перебор на симуляции (10.10)

Перебрано 98 вариантов правил теста на тех же кандидатах (общие случайные числа, 5 × 500, коммит `8f4d6d2`): порог уверенности 0,5–0,8, решение по лучшей оценке θ̂, дотестирование у границы 0–12 заданий, минимум и максимум заданий, остановка по SE, z классификации, «уровень выше в сессии», исключение семейств с низкой информацией, частичный балл, вес «информация на минуту», мир с ошибкой параметров σ 0,35 и 4 ступени. Модель, не люди. Таблицы и Парето — `docs/validation/GRADE_ACCURACY.md`, блок `/validation#grade-accuracy`.

- Было (P ≥ 0,8): точно 57,5 %, выше 4,9 %, ниже 34,8 %, без категории 5,4 %, совпадение при повторе 77,0 %, κw 0,844, 57 мин.
- Выбрано и действует по умолчанию (`ASSESSMENT_CONFIRM_LEVEL` = 0,60): точно 64,1 %, выше 6,5 %, ниже 28,0 %, без категории 3,4 %, совпадение при повторе 80,4 %, κw 0,874, 57 мин.
- При завышении ≤ 6 % (прежний ориентир) — P ≥ 0,65: точно 62,5 %, выше 5,9 %, ниже 29,8 %, без категории 4,0 %, совпадение при повторе 79,6 %, κw 0,870, 57 мин.
- Длина теста, дотестирование, остановка по SE и z меняют точность в пределах ±2 п. п.: тест упирается в 60 минут, SE в конце ≈ 0,33. Почти две трети «ниже» — кандидаты, заявившие грейд ниже своего: тест подтверждает заявленный грейд и выше не поднимает.
- Решение по лучшей оценке θ̂ без запаса уверенности даёт ≈ 65 % точно, но завышение 15–18 % — не проходит.

## Флаг «общий блок сильнее направления» (консилиум 07.10, п. 7.4)

Проверка правила: доля верных в блоке направления ниже, чем в общем, на ≥ 0,3 при ≥ 4 заданиях направления. Заявлен Middle, θ общего блока ~ N(0,5; 0,5), по 150 кандидатов; θ в направлении ниже на сдвиг.

| Сдвиг θ в направлении | Флаг сработал | Middle подтверждён | Из подтверждённых с флагом |
|---|---|---|---|
| 0,0 | 1 % | 79 % | 2 % |
| 1,0 | 21 % | 62 % | 23 % |
| 3,0 | 76 % | 21 % | 84 % |

Флаг по доле верных срабатывает и у обычных кандидатов (сдвиг 0): адаптивный тест даёт блокам задания разной трудности, поэтому сырая доля верных — грубый сигнал. В объяснение результата он не добавлен; решение по грейду не меняется (консилиум: страж направления — после 11.10 с отдельной симуляцией).
