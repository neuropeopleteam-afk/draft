# Подбор на реальных вакансиях hh.ru

**Тексты — реальные вакансии hh.ru, кандидаты — модельные (модель, не люди).** Корпус собран 2026-10-10: 414 вакансий девяти направлений (в прогоне 414, недоступно 0). Прогон 2026-10-19, код `b5449623`, алгоритм `match-v1.3`. Пересчёт: `cd backend && DATABASE_URL=sqlite:///<демо-БД> python ../tools/realdata/hh_plus.py match` с `CATALOG_EXT_ENABLED=1` (все 9 направлений) и `HH_CORPUS_DIR=<сырые вакансии>` (демо-БД: `alembic upgrade head` + `python -m app.modules.demo.seed` с тем же флагом).

**Методика.** Текст вакансии (название + описание) → разбор потребности путём правил (parse_need, без LLM) → подборка (build_selection, настройки по умолчанию) на демо-пуле: модельные кандидаты с результатами теста (модель, не люди). Метки — из полей hh.ru: направление — роль и слова названия, грейд — слово в названии, навыки — «Ключевые навыки» → теги справочника (разбору не даются). «Подтверждённые» — кандидаты, у которых грейд подтверждён тестом. Покрытие требований — доля обязательных навыков потребности, подтверждённых тестом (T1), у лучшего из первых пяти; подтверждённый фреймворк засчитывается как подтверждение базового языка (FastAPI/Django → Python, React/Vue → JavaScript, Spring → Java, PostgreSQL → SQL, Docker/Kubernetes → Linux; балл × 0,9; флаг MATCH_IMPLIED, matching/implied.py).

В репозитории — номера вакансий, ссылки и производные метки (`docs/realdata/hh_match_corpus.json`); тексты вакансий не хранятся (FTT.6: парсинг — только для тестовых данных).

## Добор уровнем выше (match-v1.3): до и после

«До» — тот же код и тот же разбор с `MATCH_GRADE_ABOVE=0` (порядок match-v1.2: только точная категория), «после» — продукт по умолчанию: если в точной категории меньше 30 кандидатов с подтверждённым или предварительным грейдом, подборка добавляет категорию на ступень выше; первые 2 места — лучшие точного уровня, дальше кандидат уровнем выше стоит выше точного, только если покрывает больше обязательного. Добор сработал: 34,8 % (144 из 414) вакансий каталога; доля кандидатов уровнем выше в первых пятёрках — 15,6 % (311 из 1990). На синтетике со скрытой истиной правило не ухудшает P@5, P@10, nDCG@5, nDCG@10 и MRR ни в одном из шести миров — `docs/validation/grade_above.json`.

## Что изменилось (W1, 19.10): по шагам
