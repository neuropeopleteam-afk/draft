## Как читать

* а) Вдали от порога — 18,2 % пула; у остальных 81,8 % (|θ − порог| < 0,45) точность 77,8 %: у порога соседний грейд статистически почти неотличим. Завышение среди «вдали» — 0,5 %; с двухэтапным подтверждением — 91,2 %.
* б) Без занижения заявки — 84,3 % пула; одна сессия на тех же кандидатах — 84,2 %, завышение с двумя этапами — 7,3 %. Заявившие ниже истинного (15,7 %) получают точный грейд в 62,4 % случаев: тест начинается с заявленного уровня, выше заявки грейд не подтверждается.
* в) Строго — весь пул, одна сессия (как в продукте сейчас): точно 80,8 %, выше 6,6 %, ниже 11,9 %, без категории 3,5 %; с двухэтапным подтверждением — 81,3 %.
* Подмножества заданы до прогона (порог 0,45 и «заявленный ≥ истинного» — из постановки), числа посчитаны один раз. Числа а) и б) — условные: они честны только вместе с долей пула и строгим числом в).
