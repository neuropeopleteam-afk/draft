## Как читать

* а) Вдали от порога — 14,0 % пула; у остальных 86,0 % (|θ − порог| < 0,45) точность 62,1 %: у порога соседний грейд статистически почти неотличим. Завышение среди «вдали» — 2,0 %; с двухэтапным подтверждением — 86,0 %.
* б) Без занижения заявки — 84,5 % пула; одна сессия на тех же кандидатах — 77,0 %, завышение с двумя этапами — 9,7 %. Заявившие ниже истинного (15,5 %) получают точный грейд в 0,0 % случаев: тест начинается с заявленного уровня, выше заявки грейд не подтверждается.
* в) Строго — весь пул, одна сессия (как в продукте сейчас): точно 65,1 %, выше 7,7 %, ниже 26,4 %, без категории 2,6 %; с двухэтапным подтверждением — 69,4 %.
