# Ограничения теста грейда (для документации и ответов жюри)

## Задания с кодом — в основном на Python

**Ограничение:** задания с кодом в основном на Python (62 семейства Backend против 4 Java, 3 Go); для кандидатов с другим
стеком часть заданий меряет знание Python — оценка может быть занижена; после финала — семейства Java/Kotlin/Go и новый
отложенный прогон.

Подробности (21.10.2026, банк 913ad19f):

- **Банк.** Языки кода по полю `language` в файлах семейств (`python3 tools/publish/bank_code_languages.py backend common`
  → `docs/validation/bank_code_languages.json`): Backend — Python 62, SQL 12, Java 4, Go 3, без кода 118; общий блок —
  Python 19, SQL 17, bash 7. Нейтрального псевдокода нет.
- **Выдача.** Семейства на Java и Go выдаются только кандидатам с java/go в стеке анкеты
  (`backend/app/modules/assessment/skill_map.py`, `stack_gate`); Python к стеку не привязан и выдаётся всем.
- **Сколько за тест.** Прогон движка BankEngine (`docs/validation/limitations/code_items_per_session.json`, модельные
  кандидаты, не люди, N = 60): у джависта у порога Middle при настройках FINAL №2 — в среднем 15,4 задания с Python-кодом
  (до 23), 0,6 — с Java; при прежних настройках стенда — 14,4 и 1,3.
- **Что требуется от кандидата.** Python-задания — «предсказать вывод» (predict_output, большинство), «найти строку с
  ошибкой» (find_bug), «выбрать исправление» (choose_fix), «открытая книга» (open_book_3step). Писать программу с нуля не
  нужно, но предсказание вывода требует знания семантики Python, а не только умения читать код.
- **Цифры FINAL №2** посчитаны на том же отборе (Python для всех), поэтому описывают выложенный тест; отбор до финала не
  меняется (решение владельца 21.10): любое изменение отбора меняет путь теста, и цифры к стенду перестали бы относиться.
