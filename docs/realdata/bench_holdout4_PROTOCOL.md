S-M 55 %, жёсткие), обе метки (rel — основная, 0–2 — справочно), 9 методов, бутстрэп 2000 по потребностям, один прогон.
Отличия — только два:

   с подтверждённым или предварительным грейдом, подтверждённые ступенью ниже идут после точного уровня и до яруса
   «грейд не подтверждён», с причиной. Веса ltr не переобучались (те же ltr_weights.json, что в FREEZE №3).
   Настройка — только на мирах разработки: `bench_holdout2.py run --dev` (зёрна 31000001/2) S-M rel nDCG@10
   0,6477 → 0,6482, l2 0,7510 → 0,7515; жёсткие — без изменений; база v1.3 — без режима (его нет в v1.3).
2. Новые отложенные миры (на разработке не использовались, в FREEZE №3 не участвовали): S-M 77021171, 77021172,
   77021173; жёсткие 77021181, 77021182.
