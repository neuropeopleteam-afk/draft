# Индекс официальных протоколов соревнований ФСП России (`fsp_protocols`)

Модуль `tools/fsp_protocols` обеспечивает автоматическое подтверждение спортивных достижений, разрядов (`МС`, `КМС`, `I`–`III`) и призовых мест кандидатов на основе **19 официальных открытых документов** Общероссийской физкультурно-спортивной общественной организации «Федерация спортивного программирования» (ОФСОО «ФСП») и Министерства спорта Российской Федерации, опубликованных на [`https://fsp-russia.ru/about/documents/`](https://fsp-russia.ru/about/documents/).

## 2. Соблюдение 152-ФЗ «О персональных данных» и 329-ФЗ «О физической культуре и спорте в РФ»

1. **Правовое основание источника:** все исходные PDF-протоколы официально опубликованы ОФСОО «ФСП» в открытом доступе на `https://fsp-russia.ru/about/documents/` во исполнение Федерального закона от 04.12.2007 № 329-ФЗ «О физической культуре и спорте в Российской Федерации» и Положения о межрегиональных и всероссийских официальных спортивных соревнованиях Минспорта России.
2. **Отсутствие персональных данных в открытом репозитории:**
   - В git-репозиторий **не коммитятся** ФИО и даты рождения спортсменов.
   - В репозитории хранятся только код сборки и проверки (`tools/fsp_protocols/`), настоящее описание и обезличенный пример из 3 записей (`docs/realdata/fsp_protocols/sample_anonymized.json`).
   - Полный серверный индекс хранится вне git по пути `/opt/spectrek_fsp/data_local/fsp_protocols/index.json` (доступ только процессу бэкенда).
3. **Режим сверки по запросу кандидата (ст. 6 и ст. 10.1 152-ФЗ):**
   - Платформа не публикует открытый каталог чужих ФИО из протоколов без регистрации самого кандидата.
   - Сверка выполняется только тогда, когда зарегистрированный кандидат сам запрашивает подтверждение своего достижения: введённое им ФИО (и опционально год рождения или название команды) нормализуется, преобразуется в `SHA-256` хэш (`key_hash`, `fio_hash`) и сопоставляется с серверным индексом.
   - Работодателю до принятия приглашения показывается только обезличенный статус подтверждения (дисциплина, разряд/место, год, номер ЕКП Минспорта) без раскрытия ФИО кандидата.

## 3. Схема записи индекса

Каждая запись в `records` серверного индекса `/opt/spectrek_fsp/data_local/fsp_protocols/index.json` имеет вид:

```json
{
  "key_hash": "<hmac-sha256>",
  "fio_hash": "<hmac-sha256>",
  "fio_norm": "<в серверном индексе вне git; в sample_anonymized.json удалено>",
  "birth_date": "<YYYY-MM-DD или YYYY в серверном индексе; в sample_anonymized.json удалено>",
  "discipline": "программирование алгоритмическое",
  "event_title": "Список кандидатов в спортивные сборные команды РФ по спортивному программированию на 2026 год",
  "ekp_no": "СБОРНАЯ-РФ-2026",
  "date": "2026-05-14",
  "place": 1,
  "rank": "КМС",
  "team": "РФСОО \"Федерация спортивного программирования в г. Москва\"",
  "region": "Москва",
  "pdf_url": "https://fsp-russia.ru/upload/iblock/503/e5miei2aikivxs93d6qz2iqfnfaf0xp1.pdf",
  "page": 4
}
```

- `key_hash` — `SHA-256` от строки `"{fio_norm}:{birth_year}"` (если год рождения известен) или от `"{fio_norm}"` (либо `team:{team_norm}` для командных отборочных протоколов без поимённого списка).
- `fio_hash` — `SHA-256` от канонического `fio_norm` (нижний регистр, `ё -> е`, один пробел), позволяет находить записи даже если кандидат не указал дату рождения или она отсутствует в протоколе соревнования.
- `ekp_no` — официальный 16-значный номер соревнования в Едином календарном плане Минспорта России (например, `2101620020035562`, `2101590019043742`, `2101770020035561`) или код всероссийского реестра.
- `pdf_url` и `page` — прямая ссылка на официальный PDF-протокол на сайте `fsp-russia.ru` и номер страницы, на которой находится строка участника.

## 5. Как пересобрать индекс и как вызывать проверку из бэкенда

### Сборка индекса из первоисточников
```bash
OPENROUTER_API_KEY=... python3 -m tools.fsp_protocols build \
  --pdf-dir /tmp/fsp_pdfs \
  --cache-dir /tmp/fsp_pdfs/cache \
  --out /opt/spectrek_fsp/data_local/fsp_protocols/index.json \
  --sample-out docs/realdata/fsp_protocols/sample_anonymized.json
```

### Проверка кандидата или команды в Python (для модуля `app/modules/fsp/`)
```python
from tools.fsp_protocols.lookup import verify_candidate_fsp

result = verify_candidate_fsp(fio="...", birth_date="2004-06-02")
# result["verified"] -> True
# result["highest_rank"] -> "КМС"
# result["achievements"] -> список словарей с discipline, event_title, ekp_no, place, rank, pdf_url, page
```
