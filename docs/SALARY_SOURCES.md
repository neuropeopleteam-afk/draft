# Рыночные диапазоны зарплат по 15 категориям

Работодатель в карточке кандидата и в форме приглашения видит **рыночный диапазон категории**, а не минимум
кандидата (минимум кандидата не отдаётся работодателю никогда). Диапазоны хранятся в справочнике категорий
(`categories.market_salary_from / market_salary_to / market_salary_median / market_sample_size / market_source /
market_as_of`) и заполняются миграцией `0003_day2_platform`. Прежние ориентиры дня 1 заменены.

## Источник

**Калькулятор зарплат Хабр Карьеры** — открытые данные, собранные из анкет пользователей.

- Страница калькулятора: https://career.habr.com/salaries
- Данные получены через публичный эндпоинт, который использует сама страница калькулятора:
  `https://career.habr.com/api/frontend_v1/salary_calculator/general_graph?spec_aliases[]=<специализация>`
  (без фильтров по городу и навыкам — вся Россия).
- **Дата выгрузки: 05.10.2026.** Сырые ответы сохранены в `docs/data_habr_salary_raw_20261005.json`.
- Окно данных калькулятора скользящее (последние анкеты на дату выгрузки), это не строго полугодовой срез.

Контекст для сверки — полугодовой отчёт Хабр Карьеры «Зарплаты в ИТ в первом полугодии 2026»
(https://habr.com/ru/specials/1060148/, 21.07.2026): медиана по ИТ — 191 000 ₽, 45 226 анкет;
статья с разбором: https://habr.com/ru/companies/habr_career/articles/1081998/. Наши медианы по категориям middle
(155–225 тыс. ₽) согласуются с этой общей медианой.

## Метод

1. Для каждой специализации калькулятор отдаёт распределение по квалификациям (Junior / Middle / Senior): 10-й, 25-й,
   50-й, 75-й и 90-й перцентили и число анкет.
2. Если направлению платформы соответствуют несколько специализаций Хабра, перцентили усредняются с весами по числу
   анкет.
3. **Диапазон категории = 25-й…75-й перцентиль** (середина рынка), округление до 5 000 ₽. Медиана хранится отдельно.
4. Суммы — в рублях в месяц до вычета НДФЛ («на руки» у Хабра не выделяется).

Соответствие направлений специализациям Хабр Карьеры:

| Направление платформы | Специализации калькулятора (`spec_aliases`) |
|---|---|
| Backend | `backend` |
| Frontend | `frontend` |
| QA | `manual_testing` + `test_automation` |
| Data/ML | `data_scientist` + `ml-engineer` |
| Информационная безопасность | `infosecspec` + `pentester` + `appsec` + `security_engineer` |

## Ограничения

- Анкетные данные самоотчётные; выборка по ИБ · Senior небольшая (94 анкеты) — диапазон ориентировочный.
- Калькулятор не различает формат работы и регион в базовом срезе; для региональных потребностей диапазон может
  быть ниже.
- Обновление: повторить выгрузку тем же эндпоинтом и новой миграцией обновить справочник (поле `market_as_of`).
