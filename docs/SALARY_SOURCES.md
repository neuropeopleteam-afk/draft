# Рыночные диапазоны зарплат по 15 категориям

Работодатель в карточке кандидата и в форме приглашения видит **рыночный диапазон категории**, а не минимум
кандидата (минимум кандидата не отдаётся работодателю никогда). Диапазоны хранятся в справочнике категорий
(`categories.market_salary_from / market_salary_to / market_salary_median / market_sample_size / market_source /
market_as_of`) и заполняются миграцией `0003_day2_platform`. Прежние ориентиры дня 1 заменены.

## Источник

**Калькулятор зарплат Хабр Карьеры** — открытые данные, собранные из анкет пользователей.

- Страница калькулятора: https://career.habr.com/salaries
- Данные получены через публичный эндпоинт, который использует сама страница калькулятора:
  `https://career.habr.com/api/frontend_v1/salary_calculator/general_graph?spec_aliases[]=<специализация>`
  (без фильтров по городу и навыкам — вся Россия).
- **Дата выгрузки: 05.10.2026.** Сырые ответы сохранены в `docs/data_habr_salary_raw_20261005.json`.
- Окно данных калькулятора скользящее (последние анкеты на дату выгрузки), это не строго полугодовой срез.

Контекст для сверки — полугодовой отчёт Хабр Карьеры «Зарплаты в ИТ в первом полугодии 2026»
(https://habr.com/ru/specials/1060148/, 21.07.2026): медиана по ИТ — 191 000 ₽, 45 226 анкет;
статья с разбором: https://habr.com/ru/companies/habr_career/articles/1081998/. Наши медианы по категориям middle
(155–225 тыс. ₽) согласуются с этой общей медианой.

## Метод

1. Для каждой специализации калькулятор отдаёт распределение по квалификациям (Intern / Junior / Middle / Senior):
   10-й, 25-й, 50-й, 75-й и 90-й перцентили и число анкет. Квалификация Intern — оплата стажировки (стипендия
   или зарплата стажёра); она же — рыночный диапазон категорий «направление · Стажёр» (миграция `ir01`).
2. Если направлению платформы соответствуют несколько специализаций Хабра, перцентили усредняются с весами по числу
   анкет.
3. **Диапазон категории = 25-й…75-й перцентиль** (середина рынка), округление до 5 000 ₽. Медиана хранится отдельно.
4. Суммы — в рублях в месяц **на руки, после вычета налогов**: именно так Хабр Карьера собирает анкеты калькулятора
   («укажите зарплату на руки» — https://habr.com/ru/companies/habr_career/articles/730078/, методика отчётов —
   https://career.habr.com/journal/salary?page=3). Поэтому в интерфейсе рыночный диапазон всегда подписан «на руки»,
   рядом даётся оценка «≈ … до вычета НДФЛ» по прогрессивной шкале 13–22 % (ст. 224 НК РФ, `app/modules/contact/salary.py`),
   а вилки работодателя, указанные «до вычета НДФЛ», перед сравнением с рынком (индекс доверия, сравнение
   кандидатов, скрытый минимум кандидата) переводятся в «на руки». До 07.10.2026 этот пункт ошибочно утверждал
   обратное («до вычета НДФЛ»); данные не менялись — исправлена только подпись и способ сравнения.

Соответствие направлений специализациям Хабр Карьеры:

| Направление платформы | Специализации калькулятора (`spec_aliases`) |
|---|---|
| Backend | `backend` |
| Frontend | `frontend` |
| QA | `manual_testing` + `test_automation` |
| Data/ML | `data_scientist` + `ml-engineer` |
| Информационная безопасность | `infosecspec` + `pentester` + `appsec` + `security_engineer` |

## Lead и Principal (флаг `GRADES_EXT_ENABLED`)

Категории «направление · Lead» и «направление · Principal» есть только при включённом флаге и только в направлениях,
где уровни проверяет банк заданий (`app/modules/catalog/levels.py`). Строки справочника добавляет служба при старте
(`app/modules/catalog/levels_seed.py`, идемпотентно; вручную — `python -m app.modules.catalog.levels_seed`), схема БД
не меняется.

- **Lead** — квалификация Lead того же калькулятора, тот же метод: диапазон p25…p75, медиана, число анкет, округление
  до 5 000 ₽, на руки. Backend, Frontend, QA, Data/ML, ИБ — выгрузка 05.10.2026 (`docs/data_habr_salary_raw_20261005.json`,
  группа `Lead`); DevOps (`devops`), инженер данных (`data_engineer`), системный аналитик (`systems_analyst`) —
  выгрузка 10.10.2026 (`docs/data_habr_salary_lead_20261010.json`).
- **Principal** — отдельной квалификации у калькулятора нет. Ориентир — верхняя четверть Lead той же выгрузки:
  «от» = p75 Lead, «до» = максимум Lead; медианы и числа анкет нет, в справочнике источник подписан «оценка».
- Mobile — алиас специализации калькулятора не найден (пробные `mobile_developer`, `android`, `ios` отдают срез по всем
  ИТ), поэтому категорий Lead/Principal у mobile нет, пока нет данных.

## Ограничения

- Анкетные данные самоотчётные; выборки по ИБ · Senior (94 анкеты), Frontend · Стажёр (78) и ИБ · Стажёр (64)
  небольшие — диапазоны ориентировочные.
- Стажировка может быть и неоплачиваемой или оплачиваться на уровне МРОТ (27 093 ₽/мес в 2026 году); нижняя граница
  p25 у Хабра выше, потому что анкеты заполняют уже работающие стажёры ИТ-компаний. Сверка: обзор Хабр Карьеры
  в журнале OTUS (медиана стажёра ≈ 64 000 ₽, 25.09.2026, https://otus.ru/journal/skolko-zarabatyvaet-programmist-i-kak-im-stat/),
  обзоры оплачиваемых стажировок (https://checkroi.ru/blog/oplachivaemaya-stazhirovka/,
  https://lab-career.ru/knowledge-base/oplachivaetsya-li-stazhirovka-v-2026).
- Калькулятор не различает формат работы и регион в базовом срезе; для региональных потребностей диапазон может
  быть ниже.
- Обновление: повторить выгрузку тем же эндпоинтом и новой миграцией обновить справочник (поле `market_as_of`).
