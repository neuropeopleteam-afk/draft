| Требование / контроль | Состояние | Проверка |
|---|---|---|
| Кнопка ФСП ID на входе и регистрации обеих ролей | включено / не настроено | видимость, ясная подпись, состояние disabled; 1440 и 390 px |

| Возрастная группа | 18+ → 16–17 → 14–15 → 18+ | сохранение, отметка согласия, возвращение к взрослой группе |
| Оффер несовершеннолетнему | нет согласия / обычный оффер / безопасная стажировка | disabled и предупреждения; отправка безопасного предложения, условия у кандидата |
| Красная кнопка | все три возрастные группы, с/без согласия | скор и порядок неизменны |

Негативные проверки: неподтверждённый вручную ФСП ID не импортирует T2; сбой реестра не стирает
прошлые достижения; отозванная отметка согласия блокирует принятие старого оффера.

## Границы

Проверки локального интерфейса — на SQLite, API 8106, Vite preview 5106.
Настоящий Keycloak стенда проверяется только чтением discovery/JWKS: сервер исполнителю доступен
только на чтение. Полный Authorization Code + PKCE поток, подпись токена, nonce/issuer/audience,
привязка/регистрация и маппинг покрыты pytest с тестовыми ответами провайдера.
Полный вход на внешнем стенде после выкладки выполняет координатор.

## Итог локального Chromium smoke, 07.10.2026

`node tools/fsp_ui_qa.mjs` — **45 из 45 проверок**, без ошибок JavaScript.
Проверка выполнена настоящими кликами в отдельной новой песочнице жюри, не в общем демо.

- На 1440 и 390 px: вход, регистрация обеих ролей, паспорт до/после импорта, командный результат,
  профиль несовершеннолетнего, безопасный оффер, входящее приглашение, отказ после отзыва согласия,
  группы 14–15 и 18+, таблица сравнения ФСП и «Красная кнопка».
- Горизонтальной прокрутки **страницы** нет. Широкие таблицы метрик имеют собственный прокручиваемый контейнер.
- Клик обновления паспорта прошёл через HTTP-мок на 8106: командное место 1, КМС, один турнир, без дублей.
- Профиль 16–17 с согласием сохраняется. Обычный оффер недоступен; после выбора стажировки,
  сокращённого времени и подтверждения проверки документов приглашение отправилось.
- Кандидат видит условия. После отзыва отметки согласия принятие ранее отправленного оффера
  возвращает понятную ошибку, контакты не открываются.
- Смена 16–17 → 14–15 → 18+ не меняет сохранённый рейтинг. «Красная кнопка» также подтверждает
  неизменность порядка и скора при смене возрастных групп и отметки согласия на всём пуле.
- В таблице ФСП виден отрицательный численный сдвиг nDCG, а не только округлённое равенство.
