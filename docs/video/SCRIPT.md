# «Драфт» — сценарий видео (3 минуты)

Формат: запись экрана рабочего сайта <https://fsp-draft.ru> (1920×1080 или 1280×720), закадровый голос участника
команды, титры с ключевыми фразами. Все демо-действия — в разделе «Демо для жюри» (`/demo`), вход в роль в один
клик. Цифры в титрах — только из `docs/NUMBERS.json`; при показе цифры на экране — подпись условий одной строкой.
Черновик видео (без голоса, с титрами) собирается командой `node docs/video/record.mjs` — см. раздел «Черновик».

Ориентир темпа: около 120 слов в минуту — спокойная речь с паузами на кадрах.

## Подписи условий к цифрам в кадре

Показываются мелким титром под цифрой, одной строкой:

- Банк заданий: автоматическая проверка банка: коммит банка ab16d27, 21.10.2026.
- Протоколы ФСП: официальные протоколы ФСП России 2025–2026 с сайта федерации; судьи, тренеры и справки исключены; 21.10.2026.


## Правила съёмки

- Только рабочий сайт и раздел «Демо для жюри»; в кадре нет служебных страниц, консоли, адресов серверов и ключей.
- Без названий соперников и внешних поставщиков; голос — живой, участник команды.
- Цифры в кадре — те же, что на `/validation` в момент записи; если NUMBERS.json обновился — пересобрать сценарий
  (`python3 docs/submission/build.py --text`) и перезаписать сцены 3, 7, 8.

## Черновик

`docs/video/record.mjs` проходит сцены 1–10 в браузере (1280×720) по сайту и записывает экран; титры из столбца
«Титр» накладываются при склейке. Результат — `docs/video/out/draft_video.mp4` (в git не входит из-за размера;
путь публикации — у оркестратора).
