# Тарифы работодателя и «Польза для ФСП»

Решение владельца 11.10: бизнес-модель «смешанная». Всё описанное ниже включается флагом `TARIFFS_ENABLED`
(по умолчанию `false`); без флага поведение платформы прежнее — методы раздела отвечают 404 `tariffs_disabled`,
лимита приглашений нет, поля `fsp_partner` в ответах других методов нет, разделы меню скрыты.

Код: `backend/app/modules/tariffs` (конфиг `plans.py`, модели, сервис, API, демо), `backend/app/fsp_cabinet/benefit.py`
(«Польза для ФСП»), миграция `tr01_tariffs`; фронтенд — `frontend/src/pages/employer/Tariffs.tsx`,
`frontend/src/ideas/fsp/Benefit.tsx`; тесты — `backend/tests/test_tariffs.py`, `e2e/tests/18-tariffs.spec.ts`.

## Правила

- **Лимит приглашений** — календарный месяц по Москве (UTC+3). Считаются все приглашения компании, отправленные
  с 1-го числа, в том числе отозванные. Превышение — `409 tariff_limit`, в сообщении — сколько использовано, когда
  обновится лимит и какой тариф даёт больше (с «Старта» — «Найм», с «Найма» — «Партнёр ФСП»).
- **Функции тарифа** — зависимость `require_feature(...)`: подключение ATS (`PUT /api/employer/ats/settings`,
  `POST /api/employer/ats/stub/connect`, `/demo/connect-all`, `PUT /providers/{code}`, `/providers/{code}/demo`),
  создание задания (`POST /api/employer/assignments`), «Рынок по hh.ru» (`GET /api/employer/market/hh`). Без функции —
  `403 tariff_feature` с названием нужного тарифа. Просмотр уже созданного (настройки ATS, задания) не ограничен.
- **Демо-счёт** — при выборе «Найма»: номер `Д-ГГГГММ-XXXXXX`, сумма, НДС 22 % внутри цены (9 900 × 22 / 122 = 1 785 ₽),
  период 30 дней, статус `demo`. Оплата не проводится, тариф подключается сразу. Таблица `tariff_invoices`.
- **«Партнёр ФСП»** — работодатель отправляет заявку (`POST /api/employer/tariff/partner-request`), ФСП выдаёт или снимает
  метку (`POST /api/fsp-cabinet/partners/{company_id}`, `grant`/`revoke`). Пока метка действует, тариф — «Партнёр ФСП»
  (сам выбрать другой нельзя: `409 partner_active`); после снятия — прежний тариф компании. Метка видна кандидату
  в приглашении и в карточке компании (`company.fsp_partner`, `GET /api/companies/{id}` → `fsp_partner`).
  Аналитик ФСП песочницы жюри меняет метку только компаний своей песочницы (`403 partner_scope`).
- **Песочница жюри**: «Северный платёж» — «Найм» по умолчанию (лимит «Старта» не мешает показу), «Логистика Онлайн» —
  «Партнёр ФСП», «Быстрый заработок» — «Старт» (`plans.JURY_DEFAULTS`). Персональные ссылки жюри не меняются.

## «Польза для ФСП» (Кабинет ФСП)

`GET /api/fsp-cabinet/benefit?days=` и `/benefit/export.csv` (UTF-8 с BOM, разделитель «;»), роли `fsp_analyst`, `admin`.

- Участник ФСП — кандидат с достижением, подтверждённым реестром (T2): именно им рейтинг подбора начисляет ФСП-бонус.
- По регионам (субъект РФ по городу профиля) и направлениям: участников ФСП, приглашены, доля приглашённых, приняли,
  наняты (исход «вышел на работу», который отметил работодатель), доля участников ФСП среди приглашённых.
- Доля приглашений с ФСП-бонусом — приглашения участникам ФСП среди всех приглашений периода.
- Вклад партнёров ФСП: число партнёров, их приглашения и доля участников ФСП в них против остальных компаний, наймы.
  Метка партнёра публична, поэтому названия компаний показаны. Связь наблюдательная, не причинная.
- Только агрегаты, минимальная группа 5 (`app/fsp_cabinet/analytics.py`, K = 5): число людей от 1 до 4 — «< 5», доли —
  только при раскрываемых числителе и знаменателе, в разбиениях — вторичное подавление (если скрыта ровно одна группа,
  скрывается и наименьшая раскрытая). Песочницы жюри в аналитику не входят.

## Демо-данные (модель, не люди)

`python -m app.modules.tariffs.demo [--reset|--delete]` (и автоматически при входе жюри, если флаг включён):
партнёры ФСП — «Демо: КиберЩит», «Демо: ПромИИ», «Демо: ЭдТех Лаб» (вымышленные, пометка «Демо: спонсорский пакет»);
«Найм» с демо-счетами «Д-ДЕМО-…» — «Демо: ФинТех Север», «Демо: ГородДанные», «Демо: Ритейл Платформа», «Демо: МедИнфо»;
демо-наймы — 45 % принятых демо-приглашений (пометка «демо-найм (модель, не люди)»). Остальные демо-работодатели —
«Старт». `--delete` удаляет только эти строки.

## Включение на сервере

1. `alembic upgrade head` (миграция `tr01`).
2. `TARIFFS_ENABLED=true` в окружении API, перезапуск.
3. `python -m app.modules.tariffs.demo` — демо-тарифы и наймы для демо-компаний.

Выключение — `TARIFFS_ENABLED=false`: данные остаются, ограничения и разделы пропадают.
