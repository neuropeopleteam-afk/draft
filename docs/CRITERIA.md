# Критерии ТЗ → что показываем → чем доказано

Сгенерировано `make criteria-doc` (`python -m app.modules.validation.criteria --md`) из того же источника, что страница `/criteria` (`GET /api/validation/criteria`). Не править руками: числа берутся из JSON расчётов `/validation` (make bench, make path-retest, make validate) вместе с подписью мира.

Формулировки — раздел 6 ТЗ дословно, по подпунктам. «Что сделать» — 1–2 клика: вход в вашу копию демо или блок /validation. Числа — из тех же расчётов, что на /validation, с подписью мира и коммита; нет расчёта — нет числа.

## Что можно проверить только здесь

- **Своя потребность → подборка.** Своими словами: требования с цитатами, подборка с доказанностью T0/T1/T2, «Что если», если подходящих мало. Написать потребность — `/employer/needs#need` (вход: работодатель); «Что если» — `/employer/needs#what-if` (вход: работодатель), потребность «…платёжного шлюза…».
- **Свой закрытый набор пар.** JSON/CSV «вакансия — кандидат» с метками: P@k и nDCG в интерфейсе, данные не сохраняются. Загрузить набор — `/validation#closed-set`.
- **Вопрос → приглашение → встречное → контакты.** Анонимный вопрос с маскированием контактов, приглашение с вилкой, встречная вилка, контакты после согласия. Как кандидат — `/candidate/invitations` (вход: кандидат без ФСП); Как работодатель — `/employer/invitations` (вход: работодатель).
- **Передача в ATS «Поток» и этап обратно.** Принятый кандидат уходит в ATS по её API; переведите его на «Интервью» — этап вернётся к обеим сторонам. Этапы из «Потока» — `/employer/ats#ats-stages` (вход: работодатель). В демо — двойник «Потока» по опубликованной спецификации API v3; с токеном компании адаптер тот же.
- **QR-демо в зале.** Телефон → мини-тест из банка без регистрации → категория → приглашение с вилкой. Открыть QR — `/jury/live`.
- **Красная кнопка.** Атакуйте сами: слейте часть банка, раздуйте резюме, смените пол и возраст — на живых данных. Атаковать — `/validation#red-button`.
- **Повтор теста и сравнение попыток.** Пройдите экспресс-тест дважды: вторая попытка — из другого набора заданий; история — в «Категории». Пройти тест — `/candidate/express` (вход: кандидат без категории); Весь путь дважды — `/validation#path-retest`.
- **Камера по согласию.** Перед тестом — выбор «с камерой» или «без»; кадры разбираются в браузере, наружу — только события. Экран выбора — `/candidate/express` (вход: кандидат без категории).
