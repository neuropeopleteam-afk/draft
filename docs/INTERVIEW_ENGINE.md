# ИИ-интервьюер: движок (устная защита ответов и короткое интервью)

Движок — `backend/app/modules/interview/engine/` (Python, внутри backend «Драфта»; написан 10.10.2026 в период
мероприятия). Интерфейс — `engine/CONTRACT.md`, развёртывание — `engine/DEPLOY.md`, ретранслятор —
`infra/relay/README.md`. Модуль с БД, роутерами и экраном кандидата — отдельно (флаг `INTERVIEW_ENABLED`, по умолчанию
выключен); движок не знает ни о БД, ни о HTTP.

## Что делает

1. **Защита (defense).** После теста с развёрнутыми ответами кандидат за 3–5 минут отвечает на 2–4 вопроса по своим же
   ответам. Вопросы строятся по плану: задания с признаками при наборе (вставка, слишком быстрый набор, метка для ИИ,
   инструкции для оценщика, уход со вкладки) — первыми, затем по длине ответа; при нехватке заданий — другой угол
   («почему так, а не иначе», «что пойдёт не так», «как проверить»). Ведущий никогда не произносит «списал» и не
   оценивает вслух; результат теста от разговора не меняется — разговор даёт работодателю отдельный вердикт.
2. **Интервью (interview).** 5–15 минут, 3–8 вопросов по навыкам, которые тест не покрыл: конкретный случай, личные
   действия, результат.

Ход разговора: сервер хранит расшифровку; `next_turn` добавляет реплику кандидата и формулирует следующую реплику
ведущего (модель `INTERVIEW_MODEL_TURN` → при сбое шаблоны по плану → в заглушке детерминированно). Вид реплики
(приветствие / вопрос k / повтор / прощание) решает **код** по плану и времени, модель лишь формулирует текст.

## Оценка — «модель предлагает, код решает»

`evaluate`: аналитик (модель `INTERVIEW_MODEL_JUDGE`) выставляет уровни по вопросам с дословными цитатами → скептик ищет
завышения и занижения → **сборка кодом**: замечание принимается, если предлагает допустимый уровень; понижение — всегда,
повышение — только с цитатой → **сверка цитат кодом**: цитата должна содержаться в указанной реплике кандидата (после
нормализации регистра, ё и пунктуации), иначе ищется в любой его реплике, не нашлась — отбрасывается; уровень без
единой подтверждённой цитаты понижается (`discrepancy` → `partial`, остальное → `no_data`) с пометкой `lowered`.

Таблица вердикта (чистая функция `verdict_from_levels`): баллы confirmed 100 / partial 60 / discrepancy 10 (interview:
strong 100 / medium 60 / weak 25), среднее по вопросам с данными; «мало данных» — меньше 2 ответов, меньше 150 знаков
или ни одного уровня с данными; защита: `confirmed` — средний ≥ 70 и нет расхождений; `discrepancies` — есть
расхождение или средний < 50; иначе `insufficient`. Подписи: «подтверждено устно / есть расхождения / мало данных».

Запрещённые основания прописаны в промтах: манера речи, акцент, волнение, паузы, личные обстоятельства; ошибки
распознавания речи не трактуются против кандидата.

## Каналы и деградация

По умолчанию — **голос** (ElevenLabs, стоковый голос, mp3 в браузере) → **текст**. Канал «аватар» (Anam, стоковый образ
поставщика, режим передачи нашего звука) существует только за флагом `INTERVIEW_ANAM_ENABLED` и **в сдаче выключен**:
решение владельца 10.10.2026 по регламенту п. 5.11 (изображения третьих лиц). Экран кандидата показывает собственную
анимацию говорящего («модель, не люди»): индикатор уровня звука из воспроизводимого mp3 (Web Audio `AnalyserNode`) —
никаких лиц третьих лиц; при `INTERVIEW_AVATAR_ENABLED` — собственный образ «ИИ-интервьюер, не человек»
(сгенерированный портрет несуществующего человека и беззвучные клипы, docs/INTERVIEW.md, раздел 2.2; к поставщику отношения не имеет).
Полный порядок деградации при включённом `INTERVIEW_ANAM_ENABLED`: аватар → голос → текст.
Распознавание — Deepgram, «нажми и говори» (целый фрагмент за запрос). Все вызовы зарубежных API с сервера идут через
ретранслятор «Мадрид» (`X-Relay-Host` + белый список хостов); без ключей — заглушка, поставщики не вызываются.
Персонаж — «Интервьюер» (`INTERVIEWER_NAME`); у поставщика включена плашка «ИИ-аватар», в продукте — подпись «модель,
не люди».

## Лимиты и стоимость

Жюри: ≤ 1 сессии на песочницу в час, ≤ 5 минут, аватар только при `INTERVIEW_JURY_AVATAR=1`. Дневной потолок
`INTERVIEW_DAILY_CAP_USD` (15). Стоимость модели — точная из `usage.cost` OpenRouter, голос/распознавание/аватар — по
ставкам. Замер 10.10.2026 (OpenRouter напрямую): реплика ведущего 2–3 с и ≈ 0.006 USD; оценка двумя проходами ≈ 50 с и
≈ 0.18 USD; озвучка фразы ≈ 1 с; расшифровка ≈ 0.2 с.

## Проверки

- `backend/tests/test_interview_engine.py` — 34 теста без сети: нормализация и план, ход разговора в заглушке, сверка
  цитат, таблица вердикта, сборка замечаний скептика, лимиты, стоимость, адаптеры с подменённым HTTP, TURN-учётные данные.
- `tools/interview_autocheck/` — автопроверка на модельных кандидатах (модель, не люди): честный / списавший /
  «плавающий» проходят защиту одних и тех же письменных ответов; итог «честных подтверждено X из Y, списавших поймано
  Z из W, …» с датой и SHA, результаты — `tools/interview_autocheck/results/`. Режим `--stub` — для CI без сети.
  Живые прогоны 10.10.2026 (OpenRouter напрямую, реплики Sonnet 4.6, оценка Fable 5.1, кандидат Sonnet 4.6):
  честных подтверждено 2 из 2 (баллы 100, 100), списавших поймано 2 из 2 («есть расхождения», 40 и 43), «плавающих»
  не подтверждено 2 из 2 («есть расхождения», 10 и 43); ни одной цитаты оценщика не пришлось убирать сверкой. В первом
  прогоне роль «плавающего» давала верные объяснения механизмов и была подтверждена (87, 100) — оценщик был прав, роль
  ужесточена (запрет объяснять причины). Стоимость сессии ≈ 0.2–0.3 USD.
