Реестр (`assessment_bank/registry.py`) читает только `families/*/*.yaml`, поэтому всё, что лежит здесь,
в тест не попадает: ни в CAT платформы, ни в симуляцию, ни в валидатор. Код и YAML сохранены без
содержательных правок (изменён только путь `generator:` и один относительный импорт), история измерений
в `calibration/params_current.json` и в отчётах панелей не трогалась — это записи о том, что было измерено.

Решение принято консилиумом 07.10 (внутренний отчёт разработки, решение 1) после второй панели
подряд с неснятыми флагами. Главный довод: продукт выдаёт задания по `prior_difficulty` из YAML
(b = −0,2 / −0,1 / 0,8 / 0,2, a ≈ 1,0–1,1), то есть CAT считает эти семейства самыми информативными
у порогов Junior и Middle и охотно их выбирает (`select_at = cut`), а по данным панели они — шум
(gc, brittle) или практически нерешаемы (leak, utf8). Для Java-кандидатов смещение системное и адресное:
через фильтр по стеку оба Java-семейства получают только они.

подробности — `calibration/panel_20261007_ext3/report.md` и внутренний отчёт разработки.

Порядок важности переделки: `session_registry_leak_bug` (ключ плохо определён — обязательно),
`gc_reachability_mcq` (вариант решает трудность — обязательно), `utf8_truncate_fix`, `brittle_render_fix`.
Дополнительно к переделке в тот же день добавлены два простых Java-семейства с бесспорным ключом (в `families/backend/`):
`backend.java.string_equals_bug` (`==` вместо `equals`; find_bug, одно сравнение в коде) и
`backend.java.list_remove_loop_fix` (удаление из `ArrayList` в цикле по индексу; choose_fix — все четыре варианта

Перекалибровка новых и переделанных семейств — одним прогоном панели (`calibration/rerun_new.py`, ≈ 0,3 $), её согласует руководитель проекта.

  трудности — правок не требует.

## Как вернуть семейство в выдачу

`git mv assessment_bank/families_retired/<блок>/<имя>.{yaml,py} assessment_bank/families/<блок>/`, в YAML
вернуть `generator: assessment_bank.families.<блок>.<имя>` (в `js_brittle_render_fix.py` — импорт
`_qa_utils` обратно относительный или оставить абсолютный), поднять `version`, прогнать
`tools/dev_family.py <FID> 200` и валидатор, перекалибровать (`rerun_new.py --include-changed`).
