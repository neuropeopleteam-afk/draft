   направлениях (меняются только название сервиса и числа), специфики направления нет (Python распределённых систем
   у аналитика, фронтенда, мобильной разработки и QA).
2. Ключ не меняется от варианта к варианту: строка дефекта `find_bug` постоянна у 60 из 60 семейств, текст верного
   патча `choose_fix` — у 80 из 80, вывод `predict_output` постоянен у 30 семейств; ключ шага 2 в трёхшаговых —
   функция ключа шага 1. Одна шпаргалка закрывает весь блок.
3. В условии `choose_fix`/`find_bug` дословно названо верное выражение или дефект; по содержанию задачи —
   уровень Junior/Middle при b = 2,4–3,0 (Principal).
4. Неверный ключ у 10 семейств `*.lead_v2.mvcc_snapshot_visibility_out` (при snap = 16 активная транзакция
   совпадает с xmax первой версии; 7 % вариантов).
