============================== security.web.html_escape_fix:1 | context: учебный каталог оборудования
Учебный каталог оборудования: серверный шаблон выводит пользовательское название `Каталог 879: <черновик> & "версия"` внутри текстового узла `<h2>`, не в URL, скрипте или атрибуте. Нужно отобразить исходный текст буквально, без удаления символов. Какое исправление выполняет HTML-экранирование за один проход?

function render(label) {
  const text = String(label).replace(/[&<>"']/g, c => "");
