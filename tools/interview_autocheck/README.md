# Автопроверка ИИ-интервьюера на модельных кандидатах

«Модель, не люди»: три роли (честный / списавший / «плавающий») проходят устную защиту одних и тех же письменных ответов
(`fixtures.py`), движок `backend/app/modules/interview/engine` ведёт разговор и оценивает. Роли — `personas.py`.

```bash
export OPENROUTER_API_KEY=...                        # ключ только в окружении, не в файлах репозитория
LLM_CHAIN=openrouter INTERVIEW_STUB=0 python3 tools/interview_autocheck/run.py --n 2
python3 tools/interview_autocheck/run.py --stub   # без сети, для CI: сценарные реплики, оценка по правилам
```

Итог печатается одной строкой («честных подтверждено X из Y, списавших поймано Z из W, …; дата; SHA; модели») и
сохраняется в `results/<дата>_<sha>.md|json` (расшифровки без персональных данных, ключей нет). Код возврата 1, если
хотя бы один честный не подтверждён или списавший не пойман.
