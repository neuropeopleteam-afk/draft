# Происхождение файлов образа интервьюера

Все файлы каталога **сгенерированы моделью** 2026-10-11 (во время мероприятия) для экрана разговора «Устная защита ответа»
и «ИИ-интервью» (флаг `INTERVIEW_AVATAR_ENABLED`). Это стилизованный рисунок — **ИИ-интервьюер, не человек**: не фото,
не портрет и не образ реального человека; чужих изображений и фотографий людей в работу не брали (регламент ЛЦТ, п. 5.11).
Звука в клипах нет — голос ведущего синтезируется отдельно (`/api/interview/sessions/{id}/speech`).

## Как получено
1. Картинка: `gpt_image_2_5_flare`, 4 варианта в цветах ФСП (градиент #1B1C21 → #402FFF, стекло) — выбрана плоская
   векторная иллюстрация (читается на 120–200 px, явно рисунок). Затем правка той же моделью: убрана стеклянная панель за
   головой (стекло — рамкой интерфейса), персонаж без изменений. Запрос: «flat vector illustration of a friendly
   gender-neutral interviewer character … clearly stylized and non-photorealistic, an original invented character that does
   not resemble any real person».
2. Клипы: `veo_3_1_fast`, первый кадр — эта картинка, 16:9, 4 с, `audio: false`; запрос — только движение лица и головы,
   неподвижная камера и фон.
3. Обработка (ffmpeg): квадрат 658×658 из кадра 1280×720 → 384×384, зацикливание «вперёд-назад» (8 с, 24 к/с),
   VP9 (webm, crf 32) и H.264 (mp4, crf 23, faststart), звуковой дорожки нет. Каждый файл ≤ 1,5 МБ (проверка —
   `backend/tests/test_interview_avatar.py`).

Права: файлы созданы командой с помощью генеративных моделей в период мероприятия и распространяются вместе с кодом
продукта (лицензия репозитория).
